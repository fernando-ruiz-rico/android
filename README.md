Este repositorio recopila diferentes recursos para aprender Kotlin desde nivel básico hasta conceptos intermedios, incluyendo clases e interfaces.

---

## ¿Qué es Kotlin?

Kotlin es un lenguaje de programación moderno, orientado a objetos, multiplataforma y ampliamente utilizado para el desarrollo de aplicaciones Android. Está diseñado para ser más conciso y seguro que Java, manteniendo compatibilidad con este.

---

[https://www.fernandoruizrico.com/programacion-con-kotlin-nivel-basico/](https://www.fernandoruizrico.com/programacion-con-kotlin-nivel-basico/)

Curso introductorio en español que cubre los fundamentos del lenguaje Kotlin. Incluye temas como:

* Tipos de datos

Es ideal para personas que comienzan desde cero en programación o en Kotlin.

### Clases e interfaces (diapositivas)

[https://fernandoruizrico.com/slides/kotlin/clases-interfaces/1](https://fernandoruizrico.com/slides/kotlin/clases-interfaces/1)

Estas diapositivas explican conceptos clave de la programación orientada a objetos en Kotlin:

* Clases: estructuras que contienen datos y comportamiento
* Interfaces: definen comportamientos que otras clases deben implementar

Es fundamental para entender cómo estructurar aplicaciones más complejas.
